# Scientific Calculator

A simple Scientific Calculator developed using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Square root
- Square
- Sin
- Cos
- Tan
- Logarithm
- Natural logarithm
- Power
- Factorial
- Pi (π)
- Clear button
- Backspace button
- Error handling

## Technologies Used

- HTML5
- CSS3
- JavaScript
